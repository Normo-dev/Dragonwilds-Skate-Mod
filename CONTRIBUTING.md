# Contributing

Keep changes small enough to review and include a test for a concrete regression.
Preserve upstream attribution and corresponding-source inventories. Contributions
to newly authored adapter code use GPL-3.0-only; follow the retained license of any
upstream subtree you edit.

Do not submit game assets, ISO contents, mappings, saves, generated collision,
local cache reports, logs, credentials or machine-specific release recipes.
Use synthetic fixtures in public tests. Describe private gameplay checks without
attaching the private inputs.

Run the relevant component tests and source checks. A successful synthetic test
does not establish gameplay acceptance, multiplayer support or public-release
readiness. Installing, committing, pushing and publishing are separate actions.
