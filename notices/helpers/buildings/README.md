# Building helper notices

Newly authored adapter code is proposed GPL-3.0-only pending author publishing
approval, consistent with the other native helpers. The proposed license text is
included; staging these files does not resolve that approval.

This helper has no external Cargo dependencies. The pinned Rust 1.96.0 standard
library/compiler notices and license texts are retained. Exact compiled Rust
and Cargo inputs are recorded in SOURCE.json and included under
helpers/buildings in the release's sources/adapter-source.zip. The standalone
component source archive additionally includes portable build instructions and
the same notices.
