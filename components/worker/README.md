# Dragonwilds Skate worker source candidate

This is an isolated source candidate based directly on Skate 3 Rust Engine snapshot `4488651c35c44365faa1ba38eed5758b6ebde714`. `LICENSE` and `UPSTREAM-README.md` are exact files from that snapshot. Four local core adaptations are represented in `patches/0001-world-geometry.patch`; no earlier unlicensed snapshot is substituted for the licensed source. The original Apache-2.0 mashup `LICENSE` and `NOTICE` remain in `skate3-mashup/`.

The worker, host adapters, and rail finder are included as source. The combined covered program must be distributed under GPL-3.0-only with corresponding source and notices; Apache component notices remain applicable. This candidate has compiled successfully and passed 39 worker tests, with five private-data tests skipped. The private world sweep passed 36 headings across nine sites and 4,465 continuous ticks. The core/data/net suites passed 838 tests and reproduced two failures also present in the pristine licensed snapshot; two private-data tests were skipped. The original host copy omits referenced test sources, so its standalone unit harness cannot compile. See UNIT-BASELINE-REPORT.json for the exact limitations. It has not been released. Converter/tooling permissions and the rest of the mod package remain separate release work.

No converted Skate assets, Dragonwilds map data, game executable, converter, native binary, or private capture is included. The upstream binary test fixture `retail-collision.rwcmset` is intentionally omitted; its included licensed generator constructs three original numeric triangles without reading game assets. Copies of upstream third-party license texts preserve their stated scope; their tools/vendor code is not included here.

## Build and test preparation

The original build used Rust 1.96.0 for `x86_64-pc-windows-msvc`. `BUILDING.md` documents requirements and commands. `Build-Worker.ps1` verifies source hashes, generates synthetic fixtures, runs the worker tests, and builds with configurable paths and Rust path remapping. It can fetch the exact locked registry dependencies, which are not bundled as source in this candidate. `THIRD-PARTY-NOTICES.md`, `DEPENDENCY-NOTICES.json`, and `TOOLCHAIN-NOTICES.json` identify their original notice texts and hashes.

Before the numeric compact-reader tests, install Python NumPy and run `python test_skate_world_export.py --fixture` from this folder. This generates only synthetic geometry. Then run `cargo test --locked --manifest-path dragonwilds-skate-worker/Cargo.toml --target-dir target`. The numeric fixture command and worker test command have passed for this candidate; exact artifact and source fingerprints are in BUILD-VERIFICATION.json. Tests marked as requiring private assets are optional and require the user's local converted copy.

Before running the licensed core/data/net library and integration tests, run `python tools/make_collision_fixture.py` from `skate3-mashup/skate/`, then `cargo test --workspace --lib --tests --target-dir ../../target`. The numeric fixture is generated locally from source; its binary bytes are not distributed here. Four retained upstream data examples reference the separate `skate-game` UI crate, which is outside this worker candidate; the explicit library/test selection excludes those examples. The separate worker and host lockfiles are retained, but the three-crate workspace now also includes the lockfile resolved during its test run.

## Changes and verification scope

The three licensed crates replace their pinned predecessors in full, including six new source/test files and the renamed network test. The candidate also restores 49 older upstream tests/examples omitted by the previous mashup copy. Unmodified licensed sources retain their exact Git blob bytes. The BoardWorld source abstraction cleanly merges with upstream's independent ExternalQueries hook. The existing host wipeout call now passes its processed input object, as required by the licensed API. The baseline's worker tests and private world sweep passed as recorded above. Its two inherited unit failures and incomplete original host test harness remain explicit limitations.

The later original throwdown/mount lifecycle uses a separate tested artifact; see `SUMMON-VERIFICATION.json` and `patches/dragonwilds-original-summon.patch`. `BUILD-VERIFICATION.json` continues to describe the preserved pre-summon baseline. See `SOURCE-PROVENANCE.json` for current source hashes and `patches/` for the changes. This remains a source candidate pending the complete mod's publication review.
